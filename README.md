# ClaudeRPG

A top-down roguelike dungeon crawler in a single HTML file, built together with Claude (Anthropic).

## How to play

Download the newest `ClaudeRPG vX.Y.html` (currently **ClaudeRPG v8.2.html**) and open it in a web browser. No install or server needed.

## What's inside

Six classes with four-tier skill trees, permadeath with family dynasties, an island home with a farm, livestock, a stable and a kennel, fishing, cooking, brewing and other mini-games, a casino, Town Favors, the Hero's Path guided tips, an autopilot, online co-op, and more. The full release history is in the game: click the version stamp on the title screen.

## Versions

Every version is kept as its own file, from `ClaudeRPG v1.0.html` to the latest, so you can see how the game grew.
